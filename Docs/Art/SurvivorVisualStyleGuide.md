## 2. 核心美术语言

- **世界观**：黑暗奇幻的像素生存战场，而不是现代、卡通休闲或科幻界面。
- **材质**：表面为磨损黑铁、暗石与旧金属；边缘有尖刺、雕刻和少量宝石镶嵌。面板内部保持深色、低反光，以保障文字与图标可读性。
- **光照**：环境主光为蓝青色月光/魔法光，局部暖光只来自火把、红色按钮或红宝石。暖冷对比服务于焦点，不能把整张界面染成紫色或红色。
- **像素感**：人物、环境和特效保持清晰的像素轮廓、有限色阶与硬边高光；不要混入厚涂、写实摄影、日漫头像或柔和矢量渐变。
- **装饰密度**：大面板可有角饰和顶部徽记，小按钮只保留框体加一颗宝石。装饰必须服务层级，避免每个元素都使用骷髅、翅膀和强光。

## 3. 颜色与状态语义

以下为从现有素材提炼的设计语义，不要求逐像素取色；实际 UI 优先采样图集本身。

| 语义        | 主色倾向               | 推荐用途                        | 禁止用途             |
| ----------- | ---------------------- | ------------------------------- | -------------------- |
| 环境底色    | 深靛蓝、近黑蓝         | 背景、留白、非交互区域          | 主要按钮填充         |
| 冷光强调    | 青蓝、月白             | 魔法阵、选中外沿、少量进度/提示 | 大面积文字底板       |
| 默认框体    | 棕黑、枪灰、暗石灰     | 面板、未选中按钮、信息条        | 稀有度或警告表达     |
| 主操作/危险 | 深红、鲜红、血色宝石红 | 开始战斗、确认、生命/危险提示   | 所有导航入口同时高亮 |
| 品质色      | 蓝 / 紫 / 金           | 装备、角色、技能或奖励的稀有度  | 普通文本和无状态装饰 |

文字为暖灰白或浅骨白，配近黑描边/阴影；不要直接使用纯白细字压在高频环境细节上。

## 4. 720 × 1280 竖屏界面布局规则

以 `720 × 1280` Canvas 为设计基准。实际运行可由 Canvas Scaler 适配，但界面原稿和生成图都使用这一比例。

```text
0 ─ 50       顶部安全区：不放关键按钮或文本
50 ─ 170     顶栏：玩家信息、资源、设置
170 ─ 680    场景焦点区：标题、月光森林、角色或主展示物
680 ─ 990    二级入口：角色 / 武器 / 局外成长等低优先级入口
990 ─ 1170   主行动区：唯一高权重的「开始战斗」按钮
1170 ─ 1280  底部安全区：只允许背景、弱装饰或版本号
```

- 顶栏使用短横向框体，资源图标在数值左侧；设置按钮放右上角，不与资源混排。
- 中央内容必须首先展示「本次要做什么」：角色选择、活动入口或战斗场景。让背景承担氛围，不将它切成许多不连续的小卡片。
- 次级入口以三枚等宽窄面板或徽章排列；默认态克制，选中或可领取时再给红宝石/冷光强调。
- 全屏只保留一个显著的红色主操作按钮。主按钮使用宽横向哥特框，离边至少 36 px。
- 功能按钮的可点击热区不小于约 `72 × 72` 设计像素；视觉框可以更精致，但不可因此缩小触控区域。

## 5. 主界面当前视觉基线

主界面参考图应表达以下信息层级，后续实现或重绘不得改变其优先级：

1. 顶部：玩家身份、货币、设置。
2. 中部：夜林场景中的当前幸存者与角色切换。
3. 下部：角色、武器、局外成长三个入口。
4. 底部：红色「开始战斗」为唯一主行动。

角色展示与背景中的蓝色幸存者使用同一像素比例和冷光方向。角色选择箭头、圆形徽章及选中态使用 `survivor01.png` / `survivor02.png` 的黑铁框与红宝石，而不是通用圆角按钮。

## 6. 素材制作与生成约束

### 优先级

1. 优先裁切、九宫格或组合现有 `survivor01.png`、`survivor02.png` 图集。
2. 现有图集没有所需部件时，再绘制或生成同风格素材。
3. AI 生成图只作为概念图、背景或独立插画时，先由美术确认；直接进入 Unity 前仍需切图、透明边缘、像素密度和导入设置检查。

### 不允许的偏离

- 不使用现代玻璃拟态、扁平圆角卡片、明亮糖果色或赛博霓虹。
- 不使用紫色城堡/厚涂英雄插画替换项目的像素夜林和蓝色幸存者。
- 不在一个页面内混用无边框图标、线性 icon 与厚重哥特框体。
- 不把红色当作普通装饰色；它应指向确认、危险、生命或当前选中状态。
- 不覆盖或重画已有图集资产来“匹配”新图；新图必须向既有资产靠拢。

生成同模块图片时，附带本节列出的三张素材，明确它们分别是背景、框体和等级徽章参考。可按实际内容替换中括号：

```text
为 Unity 2D Survivor 项目制作 [720x1280 竖屏 UI / 透明背景图标 / 像素背景]。
严格参考附图：夜林月光背景、哥特黑铁红宝石 UI 图集、品质框与徽章图集。
风格为黑暗奇幻高质量像素美术：深靛蓝夜色、青蓝月光、少量橙色火把、
暗石板与磨损黑铁、尖刺/蝙蝠/骷髅细节、血红宝石作为主操作强调。
[描述本图的单一功能与必要元素]。
避免现代扁平 UI、圆角卡片、玻璃拟态、厚涂、日漫头像、赛博霓虹、紫色城堡、
设备边框、水印和解释性标注。保留清晰像素轮廓与可用于 Unity 切图的留白。
```

若生成的是完整界面，还必须补充第 4 节的安全区与层级规则；若生成的是局部控件，须说明其默认态、选中态、禁用态和实际像素尺寸。
